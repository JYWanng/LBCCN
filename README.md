# A Lightweight and Real-Time Binaural Speech Enhancement Model with Spatial Cues Preservation
This is the official implementation of the LBCCN.

The paper associated with this project is currently under review. The code will be made publicly available once the paper has been accepted.

⚠️Note: The model is trained in a diffuse noise field with a fixed speaker direction (e.g., 45 degrees to the right of the frontal direction). Each training instance of the model targets only one direction.
